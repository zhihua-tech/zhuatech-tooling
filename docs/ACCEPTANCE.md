# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

工装台账 → 领用出库 → 生产计次 → 归还判断保养 → 维修记录 → 验收解锁 → 继续使用或停用

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 模具工装 | 寿命与保养计数，超限禁止继续生产 | 停用报废 |
| 工装领用 | 工装唯一占用与归还 | 领用出库、归还入库、撤销 |
| 生产计次 | 关联领用单记录加工次数与不良数 | 确认计次 |
| 保养维修 | 检查记录、停机修复、验收解锁 | 开始保养、提交完工、验收解锁 |
| 寿命流水 | 计次与保养重置的完整流水 | 业务动作自动生成、查询、追溯、导出 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期管理单工装领用和人工确认的生产次数，不含 PLC 自动采集、模穴级寿命建模和预测性算法。人工录入应有企业现场复核制度。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
